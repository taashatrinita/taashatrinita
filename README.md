### 🤟 ISL
#### *Bi-Directional Indian Sign Language Communication System*

</div>

> **Real-time computer vision for assistive communication — webcam in, text & speech out.**

ISL turns a live webcam feed into readable, speakable output for Indian Sign Language gestures. MediaPipe handles real-time hand landmark detection; a custom geometry-based classifier reads finger extension, spread, and orientation to identify gestures (HELLO, THANK YOU, HELP), then surfaces them as on-screen text and optional speech via pyttsx3. This MVP runs on hand-engineered landmark geometry rather than a trained classifier — no CNN training loop, by design, for a fast, judge-friendly demo. ⭐ 56 stars.

```
 ┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
 │    Webcam    │────▶│   Landmark   │────▶│   Gesture    │────▶│ Text + Speech│
 │    Stream    │     │  Detection   │     │Classification│     │    Output    │
 └──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
```

**Core Concepts:** `Real-Time CV` · `Hand Landmark Detection` · `Geometry-Based Classification` · `Assistive Communication`

**Stack:** Python · Streamlit · MediaPipe · OpenCV · pyttsx3
